## 二、学生端：4 Tab 重组合 → 【学习 / 训练 / 成长 / 我的】

### 2.1 Tab 结构

```
Tab1 学习（原"学习中心"升级，承担"学知识"）
├── 问候 + 热力图（保留）
├── 搜索栏 + 【AI 讲解】按钮（保留，AI 讲解 = 学习主入口之一）
├── 【学习任务】主色渐变主卡 ★
│     聚合：备课资料 + 待办作业 + 每日一例，角标待办数
├── 宫格（调整为 3 块，不再挤 4 块）：
│    ● 每日一例（主色）● 教材中心（靛蓝）● 刷题（苔藓绿，合并题库+基础题）
└── 底部次级行：[个性化推荐] [复盘报告]

Tab2 训练（原"病例广场"升级，承担"练能力"）
├── 病例列表（筛选/搜索，保留）
├── 顶部强化"进入问诊室"的引导（新增：今日已完成/待训练角标）
└── 子流程：问诊室 → OSCE 四维结果（问诊结束自动进入，无需单独入口）

Tab3 成长（原"错题本"升级，承担"看进步"）
├── 错题本（主内容，保留，支持按疾病系统/类型筛选）
├── 顶部数据卡：学习热力图 + 训练统计（从首页热力图逻辑复用）
├── 次级入口：复盘报告（可导出 PDF）★ 个性化推荐
└── 错题详情 → 一键"问 AI 讲解"（新增：错题归因闭环）

Tab4 我的（不变）
├── 资料 + 训练统计 + 设置 + 关于
```

### 2.2 归并说明

| 原功能 | 归并去向 |
| --- | --- |
| 错题本（原 Tab） | 下沉为"成长"Tab 的主内容（Tab 换功能） |
| 复盘报告 / 个性化推荐 | 归入"成长"Tab 次级入口 |
| 待办作业 | 并入"学习任务"主卡（聚合展示） |
| 基础题训练 + 题库 | 合并为"刷题"一张卡片（训练页内嵌题库，现状已如此） |
| 全局检索 | 首页搜索框内置（保留） |
| OSCE 结果 | 问诊子流程（自动进入） |
| 每日一例 / 教材中心 | 学习 Tab 宫格卡片 |

## 三、教师端：4 Tab 重组合 → 【工作台 / 备课 / 病例广场 / 我的】

### 3.1 Tab 结构

```
Tab1 工作台（首页，保留并增强）
├── 问候 + 班级/病例统计（保留）
├── 【智能备课】主色渐变大主卡 ★（最显眼，副标题：教学设计·课件资料·发放闭环）
├── 【预警中心】琥珀卡 + 未读红点角标 ★
├── 快捷宫格（4 块）：
│    ● SP 病例配置 ● 批阅复核 ● 作业分发 ● 学情看板
└── 次级行：[教材管理] [题库管理]

Tab2 备课（原"作业管理"Tab 换功能）
├── 智能备课列表（我的备课包，新建入口）
├── 备课包详情 = 四步工作台：
│    ① 教学设计（AI 生成/编辑）② 病例（自建/引用广场）
│    ③ 课件资料（上传 PDF/PPT/MP4/MP3）④ 发布到班级
├── 每个备课包显示作业进度 + 批阅入口（作业管理归并为备课的子流程）
└── 顶部 Tab 切换：备课 | 作业（保留原作业列表，两视图切换）

Tab3 病例广场（不变）
└── 病例列表（引用/预览试诊）—— 备课"② 病例"步骤的一键引用源

Tab4 我的（不变）
└── 资料 + 资质认证 + 设置
```

### 3.2 归并说明

| 原功能 | 归并去向 |
| --- | --- |
| 作业管理（原 Tab） | 并入"备课"Tab（备课发布生成作业，进度/批阅在备课包内查看；顶部视图切换保留作业列表） |
| 作业分发 | 备课"④ 发布"步骤 + 工作台宫格快捷 |
| 批阅复核 | 备课包详情/作业的子入口 + 工作台宫格快捷 |
| SP 病例配置台 | 备课"② 病例"子步骤 + 工作台宫格快捷（保留独立页） |
| 学情看板 | 工作台宫格 + 预警中心详情内关联 |
| 教材/题库管理 | 工作台次级行（资源库，保留独立页） |

## 四、主次层级总览（30 秒可理解）

**学生端：学习（学）→ 训练（练）→ 成长（看进步）→ 我的**
- 一级 Tab：学习 / 训练 / 成长 / 我的
- 二级主卡：AI 讲解、学习任务（学习 Tab）；问诊引导（训练 Tab）；数据卡（成长 Tab）
- 三级宫格/次级：每日一例、教材、刷题、推荐、复盘

**教师端：工作台（导览）→ 备课（准备+布置）→ 病例广场（素材）→ 我的**
- 一级 Tab：工作台 / 备课 / 病例广场 / 我的
- 二级主卡：智能备课、预警中心（工作台）
- 三级宫格：SP 配置、批阅复核、作业分发、学情看板
