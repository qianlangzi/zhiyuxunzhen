## 一、你之前跑不起来的真正原因（已修复）

**根因（3 层）**：
1. **compileSdk 版本**：项目新加了 `file_picker`（备课资料上传用），依赖要求 **compileSdk 36**，项目默认 35 → Gradle 构建失败。
   ✅ 已在 `android/gradle.properties` 全局设置 `flutter.compileSdkVersion=36`。
2. **file_picker 插件自身硬编码 compileSdk 34**（8.x/9.x 的通病），与它依赖的 lifecycle（要求 36）冲突。
   ✅ 已升级 `file_picker ^9.0.0` 并修正本机 pub cache 中插件的 compileSdk 为 36。
   ⚠️ 注意：如果以后 `flutter pub get` 重装过依赖，需要重新执行：
   ```powershell
   # 把 pub cache 里的 file_picker build.gradle 中 compileSdk 34 改为 36
   # 路径：C:\Users\qianlangzi\AppData\Local\Pub\Cache\hosted\pub.flutter-io.cn\file_picker-9.2.3\android\build.gradle
   ```
3. **网络被墙**：Gradle 从 `storage.googleapis.com` 下载 Flutter 引擎包被重置（国内网络）。
   ✅ 已在 `android/build.gradle.kts` 的 allprojects 首位加国内镜像 `https://storage.flutter-io.cn/download.flutter.io`。

> 以后再报构建失败：先看 `BUILD FAILED` 上面 "requires ... to compile against version X"，把 X 填进 gradle.properties 的 `flutter.compileSdkVersion`；若是下载类错误，检查镜像配置。

## 三、连接手机（二选一）

### 方式 A：USB 数据线（推荐，最稳）
1. 手机开启「开发者选项」→ 打开「USB 调试」
2. USB 连接电脑，手机弹窗选「允许 USB 调试」
3. 验证：
   ```powershell
   E:\Android_sdk\platform-tools\adb.exe devices
   # 看到 设备号 device 即成功
   ```

### 方式 B：Wi-Fi 无线调试（免线）
1. 手机和电脑连**同一个 Wi-Fi**
2. USB 连一次（只需这一次），执行：
   ```powershell
   E:\Android_sdk\platform-tools\adb.exe tcpip 5555
   E:\Android_sdk\platform-tools\adb.exe connect 192.168.1.4:5555
   ```
   （把 192.168.1.4 换成手机的 Wi-Fi IP，在手机「设置→关于→状态信息」里看）
3. 拔掉 USB，`adb devices` 看到 `192.168.1.4:5555 device` 即成功

## 四、运行 App（关键！真机必须指定电脑 IP）

**最重要的一点**：App 默认访问 `10.0.2.2`（这是 Android 模拟器专用的地址，**真机用不了**）。
真机调试必须指定你电脑的局域网 IP —— **当前是 `192.168.1.4`**（在电脑上 `ipconfig` 查 WLAN 的 IPv4）。

### 命令行运行（推荐，最稳）：
```powershell
cd E:\zhiyu\mobile
E:\flutter_windows_3.44.5\flutter\bin\flutter run `
  --dart-define=API_BASE_URL=http://192.168.1.4:18080 `
  --dart-define=AI_BASE_URL=http://192.168.1.4:18000
```

> ⚠️ 每次换 Wi-Fi / 重启电脑后 IP 可能变，先 `ipconfig` 确认再填。

### 编译安装（不打日志，直接装）：
```powershell
E:\flutter_windows_3.44.5\flutter\bin\flutter build apk --debug
# 产物在 build\app\outputs\flutter-apk\app-debug.apk
# 装到手机：
E:\Android_sdk\platform-tools\adb.exe install -r build\app\outputs\flutter-apk\app-debug.apk
```

## 五、Android Studio 里的正确姿势（如果你仍想用 IDE）

1. 打开项目根目录 `E:\zhiyu\mobile`（不是子目录）
2. **等右下角 Gradle 同步完成**（新增依赖后必须同步，否则构建失败）
3. 「Run 配置」→ Edit Configurations → Flutter → 添加参数：
   ```
   --dart-define=API_BASE_URL=http://192.168.1.4:18080
   --dart-define=AI_BASE_URL=http://192.168.1.4:18000
   ```
   （在 "Additional run args" 里）
4. 选择你的手机设备，点运行三角

> Android Studio 跑不起来的常见原因排序：
> 1. Gradle 构建失败（看 BUILD FAILED 原因，按第一节方法修）← 你遇到的就是这个
> 2. 没选对设备 / adb 没连上（用第三节验证）
> 3. 缺少 --dart-define 导致真机连不上后端（App 打开白屏/转圈）
