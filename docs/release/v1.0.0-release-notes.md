# 智愈寻真 v1.0.0

**新医科 AI 教研协同智能体平台 · Android 客户端首个版本**

## 📦 安装说明

- 下载下方附件 `zhiyuxunzhen-v1.0.0.apk`（约 96MB），安装到 Android 8.0+ 真机即可
- 安装时如提示"未知来源应用"，允许安装即可
- 客户端已直连线上服务器，安装后无需任何配置

## ✨ 核心功能

- 📅 **每日一例（病历训练）**：AI 病例每日推送，九段拆解 + 逐段 AI 教练点评 + 缺陷标签
- 💬 **SP 问诊训练**：与 AI 标准化病人对话问诊，Socratic 式引导 + 多维度评分
- 🧠 **错题本 · 思维分叉归因**：五阶段认知归因 + 认知偏差识别 + 分叉点定位
- 📊 **成长热力图**：考点掌握度三路加权优先级，红/黄/灰三色复习指引
- 💊 **药物库训练** · 🏥 **病例大厅** · ✅ **待办中心**
- 👩‍🏫 教师端：**AI 智能备课** · **主观题智能批改** · **学情预警** · **班级缺陷热力图**
