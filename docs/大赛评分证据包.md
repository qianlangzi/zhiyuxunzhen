# 大赛评分证据包

> 用途：把「我们做过的、真实可验证的能力」对应到大赛评分点，形成证据清单。
> 原则：每条证据必须可回放 / 可导出 / 有量化指标，禁止 mock 或截图拼凑。

## 三、可观测性证据（评审可回放）

- **统一响应契约**：所有 AI 接口返回 `status ∈ {SUCCESS, DEGRADED, FAILED, PENDING}` + `traceId` + `source/model/agent_version`。
- **错误可重试**：降级结果不写入正式成绩/学习掌握度；错题归因等支持前端重试。
- **热切换**：模型/提示词/Agent/RAG 参数存库，AI 中台每 30s 拉取重建，无需重启服务（管理 Web 端「AI 配置中心」可视化）。
