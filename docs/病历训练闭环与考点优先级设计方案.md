# 病历训练闭环 & 考点优先级图谱 设计方案

> 版本 v1.0 ｜ 2026-09-06 ｜ 面向 XH-202620 助教/助学赛道
> 目标：补齐"医学生写不好病历"+"整本书都是重点"两大真实痛点，形成 **学生练 → AI 导 → 教师评 → 数据反哺** 的完整闭环

### 1.2 核心差距（这才是痛点所在）

| # | 差距 | 后果 |
| --- | --- | --- |
| G1 | **学生写病历 = 一个纯文本框**（`todo_assignment_detail_screen.dart:497`） | 无模板、无分段、无提示，学生靠记忆硬憋 |
| G2 | **批阅发生在"写完交卷之后"** | 反馈延迟以天计，写作过程零指导；学生写完就忘，反馈无效 |
| G3 | **批阅是"整体打分"，不是"缺陷定位"** | 只知道 78 分，不知道"主诉超 20 字""鉴别诊断漏 2 条" |
| G4 | **病历缺陷没有沉淀** | 第 10 次写病历还在犯第 1 次的错，无个人能力画像 |
| G5 | **教师端只有"逐个复核"，无班级视角** | 30 份病历改 30 遍，看不到"全班 80% 漏既往史"这种共性 |
| G6 | **无"重点优先级"信号** | 学生面对整本《内科学》，不知道先背哪一章 |

**一句话诊断**：现有链路是 **"写完 → 判分"**，而医学生真正需要的是 **"边写 → 边导 → 边判 → 沉淀"**。

## 二、核心设计：病历成长引擎（MR-Coach）

### 2.1 设计主张

> **不代写，只陪伴。** AI 的定位是"身边的带教老师"，不是"代写枪手"。
> 所有 AI 输出遵循 **三级提示梯度**：提醒 → 追问 → 示范（学生点两次才给范例）。

### 2.2 五段式闭环链路

```
【0 采集】SP 问诊 / 病例大厅选题
        ↓  问诊对话自动沉淀为"素材池"
【1 结构化书写】九段分解，逐段写、逐段存
        主诉 → 现病史 → 既往史/个人史/家族史 → 查体
        → 辅助检查 → 初步诊断 → 诊断依据 → 鉴别诊断 → 诊疗计划
        ↓  每段右侧 AI 教练：规范提醒 / 追问 / 素材回捞
【2 即时批阅】提交即批（秒级），出"缺陷清单"而非只有分数
        ↓
【3 修订迭代】学生改 → AI 复批 → 生成"修订增量对比"
        ↓  同一病例最多 3 个版本，看得到成长曲线
【4 教师闭环】AI 初筛 → 教师只复核 + 班级缺陷热力图 → 一键生成讲评课件
        ↓
【5 数据反哺】缺陷打标 → 个人病历能力画像 → 汇入学情预警 + 考点优先级
```

### 2.3 关键差异化：边写边导（解决 G1/G2）

每段输入框右侧常驻 AI 教练卡，三类交互：

| 交互 | 触发 | AI 行为 | 示例 |
| --- | --- | --- | --- |
| **规范提醒** | 进入段落自动 | 提示该段规范 + 字数/要素约束 | "主诉须 ≤20 字，含症状+时限，不含诊断" |
| **素材回捞** | 学生卡住点"我没啥可写" | 从问诊对话里捞相关原话 | "患者第 3 轮说过：'夜里憋醒，得坐起来'" |
| **追问引导** | 内容明显缺要素 | 只提问，**不给答案** | "现病史里是否记录了诱因、缓解因素？" |

> 三级梯度：第 1 次点 → 追问；第 2 次点 → 定向提示；第 3 次点 → 给示范片段（带"此为范例，请勿照抄"水印）。

### 2.4 批阅维度化（解决 G3）

九段各自独立评分，权重可由教师配置（`mr_template` 表）：

| 段落 | 默认权重 | 核心评分点 |
| --- | --- | --- |
| 主诉 | 8% | ≤20 字、症状+时限、无诊断词 |
| 现病史 | 25% | 起病时序、诱因、演变、伴随、诊治经过、一般情况 |
| 既往史/个人史/家族史 | 10% | 完整性、与本次病相关性强弱 |
| 体格检查 | 15% | 顺序（一般→头颈→胸→腹→脊柱四肢→神经）、阳性+鉴别阴性体征 |
| 辅助检查 | 7% | 检查选择合理性、结果记录规范 |
| 初步诊断 | 8% | 主次排序、诊断完整性（病因/部位/分期） |
| 诊断依据 | 10% | 逐条对应、引用病历自身内容 |
| 鉴别诊断 | 12% | 数量≥2、有支持点与排除点 |
| 诊疗计划 | 5% | 针对性、检查+治疗+随访 |

输出结构（替代现在的 `mistakes: []`）：

```json
{
  "totalScore": 82.5,
  "segments": [
    {"key":"chief_complaint","score":9,"full":8,
     "defects":[{"tag":"CC_TOO_LONG","level":"minor","msg":"主诉 27 字，超出 20 字规范","suggest":"建议压缩为「反复咳嗽咳痰 3 年，加重伴发热 1 周」"}]}
  ],
  "defectTags":["HPI_NO_TIMELINE","DDX_INSUFFICIENT"],
  "reviewComment":"…",
  "highlight": [{"segment":"hpi","quote":"…","issue":"缺少缓解因素"}]
}
```

### 2.5 缺陷基因库（解决 G4）

预置缺陷标签字典 `mr_defect_tag`（约 40 条，可扩）：

| 类别 | 标签示例 |
| --- | --- |
| 规范类 | `CC_TOO_LONG` 主诉超长、`CC_HAS_DIAGNOSIS` 主诉含诊断 |
| 缺项类 | `HPI_NO_ONSET` 无起病时间、`HPI_NO_COURSE` 无演变、`PMH_MISSING` 既往史缺失、`PE_NO_NEGATIVE` 无阴性体征 |
| 逻辑类 | `TIMELINE_CHAOS` 时序混乱、`DX_NO_BASIS` 诊断无依据 |
| 思维类 | `DDX_INSUFFICIENT` 鉴别不足、`DDX_NO_EXCLUDE` 无排除点、`PLAN_GENERIC` 计划泛化 |

每次批阅打标 → 累计进 `mr_defect_record(student_id, tag_id, count, last_at)`
→ 前端渲染 **病历能力雷达图（6 维）** + **顽固缺陷 Top3**（连续 3 次出现的标红）
→ 顽固缺陷自动推送到"每日一例"选题与错题本。

## 三、教师端闭环（解决 G5）

### 3.1 三层视图

| 视图 | 页面 | 做什么 | 省多少事 |
| --- | --- | --- | --- |
| **批阅台** | `mr_console_screen.dart` | AI 已判分并标记"高置信/需复核"；教师只看需复核的，可改分改缺陷标签 | 30 份 → 看 8 份 |
| **班级热力图** | `mr_defect_heatmap.dart` | 缺陷标签 × 学生矩阵，红色密集区=共性短板 | 一眼定位"全班漏既往史" |
| **讲评生成** | `mr_lecture_gen.dart` | 勾选共性缺陷 → 一键生成讲评要点 → 直接推送到 `bprep` 备课 | 备课从 2 小时 → 10 分钟 |

### 3.2 教师闭环四步

1. **AI 初筛**：批阅结果带 `confidence`，>0.85 且无高危缺陷 → 标记"建议采纳"
2. **教师复核**：只翻"需复核"队列，改分即生效，改动记录入库（用于后续优化 prompt）
3. **申诉处理**：复用现有 `review_appeal`（V31）+ `teacher_appeals_screen`
4. **反哺教学**：热力图 → 讲评 → 备课 → 下次作业重点

### 3.3 与现有功能的衔接

- 复用 `/review/medical_record` 的 LLM 通道，新增 `mode=structured`
- 复用 `essay_review` 的"教师自定义评分要点"机制 → 病历模板权重可教师配置
- 复用 `bprep` 承接讲评课件
- 复用 `alert` 学情预警：病历能力连续 3 次低于阈值 → 触发预警

## 四、"整本书都是重点"怎么破（解决 G6）

### 4.1 重新定义问题

老师说"整本书都是重点"，潜台词是 **临床上没有非重点**。学生焦虑的真正来源不是书厚，是：
**不知道优先级** → 于是平均用力 → 时间不够 → 更焦虑。

> 所以解法不是"划重点"（老师不愿背锅，也确实不负责），而是 **给个人化的优先级排序**。
> 话术从"老师划的重点"变成 **"根据你们班真实掌握数据算出来的复习优先级"** —— 既真实，又不让老师背锅。

### 4.2 考点优先级图谱（Exam Weight Graph）

三路信号加权：

| 信号 | 来源 | 权重 | 说明 |
| --- | --- | --- | --- |
| **S1 教师权重** | 教师在 `kp_chapter_weight` 手工打分（0-5 星） | 40% | 教师最清楚考什么，也让教师有参与感 |
| **S2 数据权重** | 班级错题分布 + 病历缺陷分布 + 题目被考频次 | 40% | 客观题来自 `mistake_closed_loop`，病历来自 `mr_defect_record` |
| **S3 知识权重** | LLM 对章节打标：临床重要性 × 可考性 × 难度（离线跑一次入库） | 20% | 冷启动用，数据积累后可降权 |

融合公式：`priority = 0.4×S1 + 0.4×S2 + 0.2×S3`，再按 **个人掌握度** 打折：
`personal = priority × (1 - mastery)` → 掌握好的自动降权，不会浪费时间。

### 4.3 学生端呈现：三色优先级地图

教材中心 / 复习页新增"优先级"维度，每章一个色块：

| 色 | 含义 | 学生该做什么 |
| --- | --- | --- |
| 🔴 红 | 高优先级 + 你没掌握 | 优先攻克，系统自动推送专项练习 |
| 🟡 黄 | 高优先级 + 你已掌握 | 保持，考前快速过 |
| ⚪ 灰 | 低优先级 | 了解即可，不劝退、不制造恐慌 |

> 关键设计：**不隐藏任何章节**。整本书都在，只是告诉你先读哪章。这既尊重"整本书都是重点"的事实，又消灭了无序感。

### 4.4 冲刺模式（考前 20/80）

考前 N 天启动：基于 `personal` 排序 + 艾宾浩斯复习曲线，生成 **"最小覆盖集"**——
用 20% 的时间覆盖预计 80% 的分值，输出每日任务卡，直接接现有 `tasks` / `learning_path`。

### 4.5 心理层面（大赛叙事加分项）

- 首页文案：不说"重点"，说 **"今天优先攻克 2 章，你已覆盖 63% 高频考点"**——把焦虑转成进度条
- 成长 Tab 展示 **"掌握度曲线"**，可视化"我确实在变强"，对抗无意义感
- 教师端可发布 **"本阶段聚焦章节"**（3-5 章），给一个权威的"有限目标"

## 九、风险与对策

| 风险 | 对策 |
| --- | --- |
| AI 代写争议 | 三级提示梯度 + 范例水印 + 全文"AI 参与度"标记；批阅只看医学规范性 |
| 批阅准确性 | 教师复核改动回流，用于 prompt 迭代；高危及低置信强制人工 |
| 冷启动无数据 | S3 知识权重打底，数据积累后自动降权 |
| 工作量 | P4 可延后；P2 学生端可先做"工坊+报告"，画像放后 |
